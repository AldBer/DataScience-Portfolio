# 📊 Sales Intelligence Dashboard

Dashboard premium para análise de performance de vendas.

## 🚀 Features
- 📈 5 tipos de gráficos interativos
- 🎨 Dark/Light mode toggle
- 🔧 Filtros avançados
- ⚡ KPIs em tempo real

## 🛠️ Tecnologias
- Dash
- Plotly
- Pandas
- Bootstrap

## 📦 Instalação
```bash
pip install -r requirements.txt
python app.py
# Acesse: http://127.0.0.1:8050
```
