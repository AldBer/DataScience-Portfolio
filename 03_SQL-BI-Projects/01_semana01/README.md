# Semana 1 – Projeto Imóveis SP

Este projeto utiliza dados reais de imóveis em São Paulo para praticar consultas básicas em SQL.

## 📁 Arquivos

- `sp_properties_sample.csv`: Base de dados com bairros, área, preço, zona, etc.
- `queries_basicas.sql`: Consultas SQL introdutórias

## 🎯 Objetivo

Praticar:
- SELECT, WHERE, ORDER BY, LIMIT
- Operadores lógicos e filtros com BETWEEN, AND, OR
- Consulta de dados geográficos e por zona
